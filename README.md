# TurboWarp Music Enhanced

针对 **TurboWarp Desktop v1.15.2**（commit `965a016`）的本地化音乐创作增强版。深度适配「增强音乐」自定义扩展，提供采样级钢琴预览与脚本级音量隔离能力。

## 项目简介

本项目在 TurboWarp Desktop 原版基础上进行了最小化修改（共 4 处，见[与原版的差异](#与原版的差异)），使「增强音乐」扩展的完整功能得以生效。扩展本体随仓库提供，内嵌 15 个钢琴采样（MIDI 24–108，六半音间隔），加载即用，无需额外配置音色文件。

## 主要特性

| 特性 | 说明 |
|------|------|
| 采样级钢琴键盘预览 | 点击积木 NOTE 参数的钢琴键盘，实时播放当前乐器采样（含变调）；未加载音色时自动回退振荡器三角波 |
| 脚本级音量隔离 | `设定音量` 仅作用于当前脚本，并行脚本音量互不干扰，脚本结束后自动恢复默认值 |
| 内置钢琴采样 | 15 个采样覆盖 MIDI 24–108，随扩展内嵌，零配置即用 |
| 多乐器槽位 | 支持 1–128 个乐器编号，每个编号独立音色，随时切换 |
| 完整演奏能力 | 延音踏板（时长可调）、刮奏、鼓组、BPM 控制等 17 个积木 |

## 构建与运行

### 第一步：获取扩展

「增强音乐」扩展**不内置在应用中**（原因见[为什么需要搭配本版本使用](#为什么需要搭配本版本使用)），需手动加载：

- 仓库内文件：`extensions/enhanced-music.js`
- 或 [Release 资产](https://github.com/Xiao-Feng233/TurboWarp-Music-Enhanced/releases/latest) 直接下载 `enhanced-music.js`（约 2.7MB，含内嵌钢琴采样）

### 第二步：运行与加载

1. 下载解包版应用（[Release 资产](https://github.com/Xiao-Feng233/TurboWarp-Music-Enhanced/releases/latest) 中 `TurboWarp-Music-Enhanced-unpacked.zip`，约 415MB）
2. 解压后双击 `TurboWarp.exe` 启动，无需安装
3. 积木区 → 底部「自定义扩展」→ 打开 `enhanced-music.js`，全选复制内容 → 粘贴 → 加载
4. 积木区出现「增强音乐」分类（17 积木）

### 第三步：开始演奏

1. 拖出 `演奏音符` 积木，点击 NOTE 参数钢琴键盘试听（内置钢琴音色自动加载）
2. 想要更多音色：按[自定义采样规范](#自定义采样规范)加载文件夹

> 提示：扩展与自定义采样一致，每次启动应用后需重新加载一次。

### 从原版构建（可选）

```bash
# 基于 TurboWarp Desktop v1.15.2（commit 965a016）
# 应用[与原版的差异](#与原版的差异)所述的 4 处修改后重新打包 asar 即可
```

## 扩展使用说明

### 积木参考

#### 音色加载

| 积木 | 说明 |
|------|------|
| `加载旋律音色 乐器编号 [N]` | 打开文件夹选择器，将所选文件夹内全部采样加载为乐器编号 N 的音色 |
| `加载鼓组音色` | 打开文件夹选择器，加载鼓组采样（鼓组不占用乐器编号） |
| `当前旋律音色名称` / `当前鼓组音色名称` | 报告积木，返回当前已加载音色包的文件夹名称 |

#### 乐器控制

| 积木 | 说明 |
|------|------|
| `设定乐器为 [N]` | 切换当前乐器（范围 1–128）。**乐器编号决定音色种类**：同一编号唯一音色，加载至不同编号即获得不同乐器，可随时切换 |

#### 演奏

| 积木 | 说明 |
|------|------|
| `演奏音符 [音高] [拍数] 拍` | 阻塞式演奏。拍数结束后继续执行下一积木；无可用采样时回退三角波振荡器 |
| `演奏拍鼓 [鼓名] [拍数] 拍` | 阻塞式演奏鼓采样（鼓名格式如 `(36) 大鼓`） |
| `休止 [拍数] 拍` | 阻塞式休止 |
| `停止所有音符` | 立即停止所有播放中及延音挂起的音符 |
| `从音符 [起] 刮奏到 [终] 时长 [拍数] 拍 波形 [波形]` | 阻塞式半音逐级滑音；有采样时使用采样，否则使用所选波形振荡器 |

#### 延音踏板

| 积木 | 说明 |
|------|------|
| `延音踏板 [按下/抬起]` | 按下：音符在拍数结束后不停止，自然衰减；抬起：全部挂起音符按设定时长淡出 |
| `设置延音 [抬起时长/按下时长] 时长为 [秒] 秒` | 自定义踏板参数。按下时长 = 踏板按下时音符自然衰减时长（默认 1s）；抬起时长 = 抬起时淡出时长（默认 0.5s） |

#### 音量 / 速度

| 积木 | 说明 |
|------|------|
| `设定音量为 [V] %` | **脚本级作用域**：仅影响当前脚本，并行脚本互不干扰；脚本结束后恢复默认音量 |
| `将音量增加 [D] %` | 脚本级增量调整，基于当前脚本音量计算 |
| `设定默认音量为 [V] %` | 设置未含音量积木的脚本的默认音量（全局默认，初始 100%）；含 `设定音量` 的脚本优先使用脚本音量 |
| `设定速度为 [BPM] BPM` | 全局速度（20–500） |
| `将速度增加 [D]` | 全局速度增量调整 |

### 自定义采样规范

#### 旋律音色

| 项目 | 要求 |
|------|------|
| 文件命名 | 文件名必须为 MIDI 编号，如 `60.ogg`（中央 C）、`72.ogg`（高八度 C） |
| 支持格式 | `.ogg` / `.mp3` / `.wav` |
| 采样时长 | 单个采样（有效单音）建议 **≥ 4 秒**；过短会导致长音符被截断，延音踏板效果不明显 |
| 覆盖密度 | 建议每 4–8 个半音放置一个采样（覆盖 MIDI 36–96 约需 16 个）；采样不足时自动选择最近的较低音采样变调播放 |

#### 鼓组音色

| 项目 | 要求 |
|------|------|
| 文件命名 | 文件名即鼓件名，如 `Bass Drum.ogg` → 鼓件名 `Bass Drum` |
| 支持格式 | `.ogg` / `.mp3` / `.wav` |
| 播放规则 | 鼓采样**不做变调**，原声播放 |
| 名称查询 | 加载完成后使用 `可用鼓件` 报告积木查看全部鼓件名 |

### 多乐器机制

- 使用 `加载旋律音色 乐器编号 [N]` 将采样集存入指定编号
- 使用 `设定乐器为 [N]` 切换当前演奏乐器
- 各编号音色互不影响；加载到编号 1 会覆盖内置钢琴采样

### ⚠️ 采样持久性

自定义采样仅存在于应用内存（RAM）中，**每次启动应用后需重新加载**；关闭应用后采样数据丢失。仅内置钢琴（乐器编号 1）常驻。

## 与原版的差异

本仓库对原版仅做 4 处修改，全部位于 `dist-renderer-webpack/editor/gui/`：

| 文件 | 修改内容 |
|------|---------|
| `index.js` | ① 覆写 `Blockly.FieldNote.playNote_`：钢琴键盘预览优先播放增强音乐当前乐器采样（变调精确），无采样时回退三角波（增益 0.6）；② 兼容层 `stackFrame` 改为线程级持久（`thread.compatibilityStackFrame`），为脚本级音量隔离提供底层支持 |
| `gui.html` | 引入内置节奏鼓组扩展脚本 `<script src="rhythm-drum.js"></script>` |
| `rhythm-drum.js` | 内置「节奏鼓组」扩展（9 积木，随应用分发，源码不在本仓库） |

其余文件保持原版 v1.15.2 不变。

> ⚠️ **维护状态声明**：「增强音乐」扩展中的**鼓组部分**（`演奏拍鼓` 积木及 `加载鼓组音色`）为早期开发产物，**未经完整维护与测试**，可能存在功能缺陷，请谨慎使用。旋律演奏、延音踏板、刮奏等功能可放心使用。

## 为什么需要搭配本版本使用

「增强音乐」扩展本体可在任意 TurboWarp（在线版 / 官方桌面版）通过「自定义扩展」加载，但以下两项核心功能依赖本仓库的底层修改：

| 功能 | 依赖的修改 | 未搭配本版本时的行为 |
|------|-----------|---------------------|
| 钢琴键盘预览播放采样 | `index.js` 覆写 `Blockly.FieldNote.playNote_` | 琴键预览仅为原始三角波提示音，无法听到乐器音色 |
| 脚本级音量隔离 | `index.js` 兼容层 `stackFrame` 线程级持久化 | `设定音量` 退化为全局音量，并行脚本相互覆盖 |

即：**仅加载扩展 = 可播放采样，但预览为三角波、音量为全局**；**搭配本版本 = 完整功能**（采样预览 + 脚本级音量）。
