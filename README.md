# TurboWarp Desktop 音乐增强版

> 基于 **TurboWarp Desktop v1.15.2**（commit `965a016`，GPL-3.0）修改，为「增强音乐」扩展深度适配的本地音乐创作版本。

## ✨ 特色功能

- **钢琴键盘实时预览**：点击积木中 NOTE 参数的钢琴键盘，立即播放「增强音乐」扩展当前乐器的采样音色（变调精确），未加载音色时自动回退三角波
- **「增强音乐」扩展**：内嵌 15 个钢琴采样（MIDI 24–108，每 6 个半音一采样），加载即弹，无需任何配置
- **脚本级音量隔离**：每个脚本可独立设置音量，并行脚本互不干扰

## 📦 随附扩展

| 文件 | 说明 |
|------|------|
| `extensions/enhanced-music.js` | 增强音乐扩展（17 积木 + 内置钢琴采样，约 2.7MB，通过「自定义扩展」加载） |

## 🎵 增强音乐扩展 — 积木说明

### 音色加载

| 积木 | 用途 |
|------|------|
| `加载旋律音色 乐器编号 [N]` | 弹出文件夹选择框，将文件夹内所有采样加载为**乐器编号 N** 的音色 |
| `加载鼓组音色` | 弹出文件夹选择框，加载鼓组采样（鼓不参与乐器编号） |
| `当前旋律音色名称` / `当前鼓组音色名称` | 报告器，显示当前已加载的音色包文件夹名 |

### 乐器控制

| 积木 | 用途 |
|------|------|
| `设定乐器为 [N]` | 切换当前乐器（1–128）。**乐器编号决定音色种类**：同一个编号只能有一种音色，加载到不同编号即得到不同乐器，随时切换 |

### 演奏

| 积木 | 用途 |
|------|------|
| `演奏音符 [音高] [拍数] 拍` | 阻塞式演奏音符，拍数结束后才执行下一块；无采样时回退三角波 |
| `演奏拍鼓 [鼓名] [拍数] 拍` | 阻塞式演奏鼓采样（鼓名用 `(36) 大鼓` 格式） |
| `休止 [拍数] 拍` | 阻塞式休止 |
| `停止所有音符` | 立即停止所有正在播放和延音挂起的音符 |
| `从音符 [起] 刮奏到 [终] 时长 [拍数] 拍 波形 [波形]` | 阻塞式刮奏：半音逐级滑音，可用采样播放，无采样用所选波形振荡器 |

### 延音踏板

| 积木 | 用途 |
|------|------|
| `延音踏板 [按下/抬起]` | 按下后音符在拍数结束后不停止（自然衰减）；抬起时全部挂起音符按设定时长淡出 |
| `设置延音 [抬起时长/按下时长] 时长为 [秒] 秒` | 自定义踏板参数：按下时长 = 踏板踩下时音符自然衰减时长（默认 1s）；抬起时长 = 抬起时淡出时长（默认 0.5s） |

### 音量 / 速度

| 积木 | 用途 |
|------|------|
| `设定音量为 [V] %` | **脚本级作用域**：只影响当前积木所在的那一段脚本，并行脚本互不干扰；脚本结束后自动恢复默认音量 |
| `将音量增加 [D] %` | 同上，增量调整（基于当前脚本音量） |
| `设定默认音量为 [V] %` | 设置**没有音量积木的代码段**的默认音量（全局默认，初始 100%）；有 `设定音量` 的脚本仍优先用自己的音量 |
| `设定速度为 [BPM] BPM` | 全局速度（20–500） |
| `将速度增加 [D]` | 全局速度增量调整 |

## 🎧 自定义采样使用说明

### 旋律音色（多乐器）

1. 准备音频文件夹，**文件名必须是 MIDI 编号**（如 `60.ogg` = 中央 C，`72.ogg` = 高八度 C）
2. 支持格式：`.ogg` / `.mp3` / `.wav`
3. **采样建议**：单个采样（有效单音）长度最好 ≥ 4 秒，太短会导致音符在延长时被截断，延音踏板效果不明显
4. 点击 `加载旋律音色 乐器编号 [1]` → 选择文件夹 → 采样存入**乐器 1**
5. 换一套采样加载到 `乐器编号 [2]`，用 `设定乐器为 [1/2]` 切换
6. 建议每 4–8 个半音放一个采样（覆盖 MIDI 36–96 约 16 个即可），采样不足时扩展自动找最近的低音采样变调

### 鼓组音色

1. 文件名即鼓件名（如 `Bass Drum.ogg` → 鼓件名 `Bass Drum`）
2. 支持格式：`.ogg` / `.mp3` / `.wav`
3. 点击 `加载鼓组音色` → 选择文件夹 → 完成后用 `可用鼓件` 报告器查看名称列表
4. 鼓采样**不做变调**，原声播放

### ⚠️ 重要：采样不持久化

自定义采样只存在于**应用内存（RAM）**中，**每次启动 TurboWarp 后都需要重新点击加载**。只有内置钢琴（乐器编号 1）是常驻的。关闭应用后加载的采样全部丢失，不会保存到磁盘。

## 🔧 与原版的差异

本仓库仅修改原版 4 处（均在 `dist-renderer-webpack/editor/gui/`）：

| 文件 | 改动 |
|------|------|
| `index.js` | ① 覆写 `Blockly.FieldNote.playNote_`：点击钢琴键盘优先播放增强音乐当前乐器采样，回退三角波（增益 0.6）；② 兼容层 `stackFrame` 改为线程级持久（`thread.compatibilityStackFrame`），使扩展支持脚本级音量隔离 |
| `gui.html` | 添加 `<script src="rhythm-drum.js"></script>` |
| `rhythm-drum.js` | 新增内置节奏鼓组扩展（9 积木，已随应用内置，源码不在本仓库） |

其余全部保持原版 v1.15.2 未动。

## 🚀 快速开始

1. 下载/解压后双击 `TurboWarp.exe`（无需安装）
2. 打开「增强音乐」扩展：积木区 → 自定义扩展 → 粘贴 `extensions/enhanced-music.js` → 加载
3. 拖出「演奏音符」，点击 NOTE 参数钢琴键盘试听（内置钢琴）
4. 想要更多音色：按「自定义采样使用说明」加载文件夹
